  1. NotesWala is a full-stack web application designed to help students easily access academic resources such as notes, question papers, and chapter-wise PDFs. The platform allows users to browse and download study materials in a simple and organized way, making learning more efficient and accessible. It also includes features like categorized content, user-friendly navigation, and responsive design for a smooth experience across devices.

  2. On the frontend, the application is built using React.js with Vite, along with JavaScript, HTML, CSS ,and TailwindCSS to create a fast and interactive user interface. It uses dynamic routing and reusable components to manage different sections like notes, PDFs, and question papers efficiently.

  3. On the backend, Node.js and Express.js are used to handle API requests, manage data, and implement application logic. The project follows a structured architecture using routes and models for clean and scalable development. Nodemon is used during development for automatic server updates. Overall, this project demonstrates my ability to build a complete full-stack application focused on solving real student needs.
